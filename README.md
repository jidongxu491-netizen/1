# 拾味小馆 · 餐馆首页

基于 Vite 的静态餐馆首页项目（由单文件页面迁移而来）。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（默认 http://localhost:5173）
npm run build   # 构建到 dist/
npm run preview # 本地预览构建产物
```

## 目录结构

- `index.html` —— 页面结构
- `src/style.css` —— 全部样式
- `src/main.js` —— 交互逻辑
- `vite.config.js` —— Vite 配置
